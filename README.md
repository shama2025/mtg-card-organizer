# ManaVault

## Project summary:
 ManaVault is a digital collection app for magic the gathering. The purpose of this project was to streamline a storage and searching of a user's collection without going through binders and boxes.

## Technology Used

### In-Curriculum Tech
ManaVault is a full stack application built using MySQL as the database, Java's SpringBoot library as the api, and React JS as the frontend.

### Out-Of-Curriculum Tech
The tech used outside of this capstone includes Tailwind for styling, Bcrypt for password protection, calling an external API (Scryfall API), and integrating Ollama using Spring AI
